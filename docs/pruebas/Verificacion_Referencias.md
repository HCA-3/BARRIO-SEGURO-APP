# Verificación de 3 referencias bibliográficas

Verificado con búsqueda web real (Crossref, PLOS ONE, RePEc/IDEAS, Springer,
y el repositorio de GitHub citado), no de memoria.

## [30] — CORREGIR

> D. Hernández, C. Pulido y F. Gómez, "Quantifying fairness in spatial
> predictive policing," Artif. Intell. Law, 2026, doi: 10.1007/s10506-026-09508-7.

- El DOI `10.1007/s10506-026-09508-7` **no resuelve a nada** (no aparece en
  Crossref ni en ninguna base indexada).
- Sí existe un trabajo real con ese título exacto: repositorio de GitHub
  Pages de `dieahernandezcas`
  (https://dieahernandezcas.github.io/Quantifying_Fairness_in_Spatial_Predictive_Policing_Repository),
  sobre modelos SEPP/KDE/Naive KDE y fairness (Gini, max-min) con datos de
  Bogotá y Chicago -- el tema SÍ coincide.
- Esa página dice explícitamente: *"This article is currently undergoing
  major peer review. Contact details and citation instructions will be
  provided upon completion of the review process."* (badge "Status: In
  Development"). **No lista autores, no menciona la revista "Artificial
  Intelligence and Law", no da año ni DOI.**
- Conclusión: el trabajo probablemente existe pero **todavía no está
  publicado** -- la revista, el año (2026) y el DOI de la cita parecen
  inventados o anticipados, no verificables hoy. **No se puede confirmar
  "D. Hernández, C. Pulido y F. Gómez" como autores** con la información
  disponible públicamente.
- **Recomendación:** no citar como artículo de revista publicado. Si se
  quiere citar, usar el repositorio de GitHub como "recurso en línea" /
  "trabajo en revisión, sin publicar" (sin DOI, sin volumen, sin página),
  o esperar a que termine la revisión por pares y la página publique los
  datos de citación reales.
